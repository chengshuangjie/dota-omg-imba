## 2. 安全实现设计（待落地，本报告不写代码进工程）

### 2.1 单位判定函数（新增，纯函数，只读既有分类）
```
function B1133IsNormalNeutralCreep takes unit u returns boolean
    if u==null then return false
    if GetOwningPlayer(u)!=B7 then return false          // 排除召唤物/幻象/玩家控制/线上兵/Roshan归属外单位
    if IsUnitType(u,UNIT_TYPE_HERO) then return false
    if IsUnitType(u,UNIT_TYPE_STRUCTURE) then return false
    if IsUnitType(u,UNIT_TYPE_SUMMONED) then return false
    if IsUnitIllusion(u) then return false
    return B832WardCreep(u)                              // 复用 36 rawcode 白名单（39309）
endfunction
```
- 归属门 `==B7` 即排除：陈/魅惑夺走后改归属玩家的野（玩家控制）、英雄召唤物（归属召唤师）、幻象（归属同英雄且 IsUnitIllusion 已挡）、线上兵（归属 Z7/A7）。
- `B832WardCreep` 内部已排除 HERO/STRUCTURE/SUMMONED/ILLUSION（39300）与 Roshan/Boss/dummy（白名单不含 'n00L'）。

### 2.2 事件注册（与 Roshan 同范式，单点注册）
```
set t=CreateTrigger()
call TriggerRegisterPlayerUnitEvent(t, B7, EVENT_PLAYER_UNIT_DEATH, null)
call TriggerAddCondition(t, Condition(function B1133DropCond))   // =B1133IsNormalNeutralCreep(GetTriggerUnit())
call TriggerAddAction(t, function B1133DropAction)
```
- 只挂 `EVENT_PLAYER_UNIT_DEATH`（原生每死亡触发一次），**不**注册 UNIT_STATE_LIFE 事件（避免与 B832Ward 的双事件同因）。
- 位置建议：紧邻 `war3map.j:243290`（ZI/Roshan 注册段）之后，初始化段内。

### 2.3 每死亡最多一次（双保险）
- 原生 DEATH 事件本身每单位只触发一次；
- 再叠加既有状态位范式（2.5）：动作开头
  `if LoadBoolean(L7, GetHandleId(u), StringHash("B1133DropGiven")) then return`
  命中后 `call SaveBoolean(L7, GetHandleId(u), StringHash("B1133DropGiven"), true)`。
- 野怪重生是**新单位新 handle**，按设计允许再次roll（Dota 刷野即如此）；同一单位任何嵌套/重入路径只发一次。

### 2.4 10% 概率与同步
- 动作内（服务端共享上下文，**不得**包进 `if GetLocalPlayer() then`）：
  `if GetRandomInt(1,10)==1 then ... CreateItem(...) ... endif`
- 依据：本图共享动作内已用 `GetRandomInt`（`war3map.j:44648/44654` 在 WU8 内）；本图局部分支仅用于文字（如 `war3map.j:44672` 的 `TEXTDUR[GetPlayerId(GetLocalPlayer())]`）。随机数在网络事件动作链中按相同调用序在所有客户端一致推进；`CreateItem` 是共享原生，所有客户端落点一致 → 不脱战。

### 2.5 掉落池构建（初始化时一次，复用价格/可掉表）
```
// B1133Pool[1..B1133PoolN]，初始化段调用一次
loop i=1..EV (521)
    id=SU[i]
    price=Get_Item_Price(id)
    if price<=0 or price>1000 then continue
    probe=CreateItem(id,9999,-9999)
    ok = (GetItemType(probe)==ITEM_TYPE_PURCHASABLE)   // 可购买；与 44656 同语义
    call RemoveItem(probe)
    if ok then 入池
endloop
```
- 空池（B1133PoolN==0）→ 动作直接 return，不掉任何东西、不报错。
- 只取 `SU[]` 基础件，不取 `ZU[]` 升级件/`BU[]` 组件，避免重复与合成件；价格上限 1000 金币封顶价值。

### 2.6 落点坐标边界安全
- 沿用本图既有惯例：`CreateItem(poolPick, GetUnitX(u), GetUnitY(u))`（与 `war3map.j:44659`、`war3map.j:45461` Aegis 神符完全一致）。
- 本图未使用 `GetMapBoundary*` 原生（全文件 0 命中），也无统一边界 rect 常量；野怪死于预刷野点，地形合法。**不引入新坐标/不做位移**，因此无越界风险；这是与现有掉落行为一致的选择，不是遗漏。
- 可选抖动（如需）：在 ±64 内 `GetRandomReal`，但必须与 2.4 同一共享动作内。

## 3. 同步与刷取风险清单

| 风险 | 结论 | 依据/缓解 |
|---|---|---|
| 客户端脱战 | 不引入 | 随机与 CreateItem 均在共享动作；不进 GetLocalPlayer 分支 |

| 刷野 farm 经济膨胀 | 有上限 | 单价 ≤1000、10%/死亡、空池保护；仅基础消耗/小件 |
