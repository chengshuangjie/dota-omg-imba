## 2. 核心定位结论

### 2.1 多重施法掷骰 = `EUD`（唯一集中概率点）
- 函数：`EUD takes unit ZX7 returns integer`，**war3map.j:81627-81725**。
- 技能 rawcode：`'A088'`（Ogre Magi Multicast）。
- 概率原语：`GetPrdRandom(caster, key, chance)`，**chance 单位 = 百分比整数（out of 100）**。
- 等级由 `V77=B287_GetUnitAbilityLevel(ZX7,'A088')` 决定（BOSS/ISLABIKE 覆盖）。
- 掷出 r 后由全局 cast 钩子消费（`IFG`@201347、`SuijiMode_DurationMulticastOnCast`@201663、`SuijiMode_StartScriptedFlight`@189429 等 30+ 处）。

| 等级 | 神杖(HaveA) | 原概率链（chance 列） | 掷出 r |
|---|---|---|---|
| L1 | 否 | 40 → r=2 | 2 |
| L1 | 是 | 5→r=5；50→r=2 | 5 / 2 |
| L2 | 否 | 25→r=3；50→r=2 | 3 / 2 |
| L2 | 是 | 5→r=5；30→r=3；60→r=2 | 5 / 3 / 2 |
| L3 | 否 | 15→r=4；30→r=3；60→r=2 | 4 / 3 / 2 |
| L3 | 是 | 5→r=5；20→r=4；40→r=3；80→r=2 | 5 / 4 / 3 / 2 |

**×2 设计**：
- 概率：`new = RMinBJ(old*2, 100)`。注意 80→100（封顶）、60→100（封顶）、50→100（封顶）——多档会撞顶。
- 次数 r：`new_r = IMinBJ(old_r*2, 6)`（安全帽 6）。即 r=2→4、r=3→6、r=4→6、r=5→6。

### 2.2 集中攻击触发概率块 = `TPA`（被动晕/暴击等）
- 函数：`TPA takes nothing returns nothing`，**war3map.j:222867-222910**。
- 全部走 `GetPrdRandom(WXX, skill, probability)`，chance 为百分比整数。
- 这是**共享动作内**的触发判定（攻击事件回调），随机推进与 `B67` 伤害在同一同步链 → 改 probability 常量是同步安全的。

### 2.3 通用弹射链 = `B582_BounceChain`
- 销毁/超时：`B582_DestroyBounceChain`@66256、`B582_BounceChainTimeout`@66285。
- 链状态存 `TABLE_P`：child 0=caster、1=hitGroup、2=level、**3=times(剩余弹射)**、**4=max(上限)**。
- 每跳 `GroupEnumUnitsInRange(...,400,...)`（66339 / 82362）——**400 是距离，不改**。
- 具体技能的 times/max 在各技能 cast 入口写死（见 §3.C）。

### 3.A 多重施法概率 + 次数（EUD @ 81627）
- **原公式**：`if GetPrdRandom(ZX7,'A088'+k, C) then set r=R`
- **新公式（概率）**：`if GetPrdRandom(ZX7,'A088'+k, IMinBJ(C*2,100)) then set r=IMinBJ(R*2,6)`
- **安全帽**：概率 100；次数 r 帽 6。
- **同步**：`GetPrdRandom` 在共享攻击/施法动作链内，按调用序推进；不在 `GetLocalPlayer` 分支 → 安全。

## 4. 安全设计（落地约束，本批不改工程仅记录）

1. **概率封顶 100%**：所有 `GetPrdRandom(...,C)` 改 `IMinBJ(C*2,100)`。`GetPrdRandom` 底层若接受 >100 会直接必触发 → 必须夹。
2. **次数安全帽（数量安全帽）**：弹射帽 8（A05T 例外保持 99）、召唤帽 8、弹道帽 12、multicast r 帽 6。
3. **容量检查**：×2 后回查对应 group/hashtable 清理路径（`B582_DestroyBounceChain`、`B1052FamiliarSpawn`、`FYD_TS` 递归 `SaveInteger(TABLE_P,h,3,times-1)`）确认 `times` 减到 0 仍能正常销毁，不会因 times 变大而泄漏定时器。
4. **距离拆分**：凡 ×2 次数的函数同时含 `GroupEnumUnitsInRange(...,400)` 或 `NHX(...,1000,...)` 速度参数，**只改 times/max 字面量，半径/速度行原样保留**。
5. **同步**：所有改动点都在共享施法/攻击动作链（`EVENT_PLAYER_UNIT_SPELL_EFFECT` / 攻击事件回调），禁止移入 `GetLocalPlayer()`；`GetPrdRandom` 与 `B67` 伤害同序推进。
6. **防叠乘**：
   - multicast 额外召唤路径（`SuijiMode_BeastmasterCallWildMulticastExtra`）本身是 `EUD` 产物 → 底座召唤只数不 ×2，否则与 r×2 叠乘。
   - `'A0MX'` 醉拳暴击已有 `RMinBJ(.45)` → 不再 ×2。
   - `B945SpellData` 蓝耗表只读。
7. **原生数据技能**：`W6E('A10D',7,7,7,7,125,130,...)`（128521）里的 125/130 是伤害/距离，非次数；底座召唤/弹射次数在 SLK 物编里（脚本不可见）→ 脚本层 ×2 只覆盖脚本写死的 times/max/count 字面量，原生部分不覆盖。
